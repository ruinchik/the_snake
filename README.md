# Игра "Змейка" (Python + PyGame)

Классическая игра "Змейка" с современной реализацией на Python.



##  Особенности
- Полностью рабочая версия на Python 3.12+
- Использует библиотеку PyGame
- Плавное управление с обработкой зажатых клавиш
- Система счета
- Переход змейки через границы экрана
- Возможность перезапуска игры (клавиша R)

##  Управление
- **Стрелки** ← ↑ → ↓ — движение змейки
- **R** — перезапуск игры
- **ESC** — выход из игры

##  Установка и запуск

### Требования
- Python 3.12 или выше
- Библиотека PyGame
